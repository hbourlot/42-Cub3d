## Overview

**42-Cub3d** is a lightweight 3D rendering engine that transforms 2D map data into immersive environments using raycasting techniques. Built with a modular architecture, it integrates graphics, input handling, and game logic seamlessly to create interactive experiences.

---

## Why 42-Cub3d?

This project empowers developers to craft detailed, real-time 3D scenes with ease. The core features include:

- 🔷 **Raycasting Rendering**: Efficiently projects 3D perspectives from 2D maps, delivering immersive visuals.  
- 🧩 **Modular Design**: Facilitates easy extension and customization of graphics, input, and game mechanics.  
- 🎨 **Texture & Sprite Support**: Adds realism with textured walls, sprites, and dynamic environment elements like doors.  
- 🛡️ **Robust Map Validation**: Ensures map integrity and readability, preventing gameplay issues.  
- 🖌️ **Advanced Graphics Utilities**: Includes color management, pixel manipulation, and line drawing for precise rendering.
